# The Funniest Office Joke, Judged Head to Head

Entry for the make.fun bounty **"The Funniest Office Joke, Judged Head to Head"** — an office joke generator that writes short, punchy workplace jokes and pits them head to head so the funniest one wins.

## How it works

Run the entrypoint:

```bash
python3 main.py
```

It generates office-themed jokes and ranks them head to head, surfacing the single funniest one.
